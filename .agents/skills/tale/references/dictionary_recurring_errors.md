# ASD-STE100 Issue 9 — Part 2: Recurring Errors & Word Replacements

This reference contains all items in the **List of Recurring Errors** (Part 2, Pages 2-0-17 & 2-0-18) and core vocabulary mappings from ASD-STE100 Issue 9.

## 1. Complete Official List of Recurring Errors

| **complete** *(adj)* | **COMPLETED** *(adj)* | "The complete assembly..." | "The completed assembly..." |
| **damage** *(v)* | **DAMAGE** *(n)* / **CAUSE DAMAGE TO** | "This may damage the unit." | "This can cause damage to the unit." |

## 2. Common Technical & Software Engineering Conversions

| Common Engineering Term | ASD-STE100 Issue 9 Approved Construction |
|:---|:---|
| *execute / run (v)* | **DO** *(v)* (e.g. "Do the test", "Do the script") |
| *verify / validate (v)* | **MAKE SURE** *(v)* / **CHECK** *(n)* (e.g. "Make sure that the signature is valid") |
| *terminate / abort (v)* | **STOP** *(v)* (e.g. "Stop the process") |
| *initialize / instantiate (v)* | **START** *(v)* / **PREPARE** *(v)* (e.g. "Start the server instance") |
| *modify / alter (v)* | **CHANGE** *(v)* (e.g. "Change the configuration") |
| *display / render (v)* | **SHOW** *(v)* (e.g. "Show the error modal") |
| *obtain / retrieve (v)* | **GET** *(v)* (e.g. "Get the token from storage") |
| *transmit / dispatch (v)* | **SEND** *(v)* / **TRANSMIT** *(v)* |
| *prevent / mitigate (v)* | **PREVENT** *(v)* |
| *inspect / audit (v)* | **EXAMINE** *(v)* / **DO AN AUDIT OF** |
